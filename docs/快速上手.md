# 快速上手（5 分钟）

> 面向**使用者**，不需要懂编程。想知道"它到底能干什么"，看 [README](../README.md)；
> 想查每个配置项的含义，看 [运行与配置文档](运行与配置文档.md)。

## 它是什么

一个**跑在你自己电脑上**的邮件 + 日历助手（网页界面，浏览器打开就能用）：

- 把收件箱读一遍，告诉你**哪些邮件需要你处理**、每封一句话讲清是什么事，并**起草好回复**等你审核；
- 邮件里的时间点可以**一键转成日程**；日程也能用一句话创建、修改、删除；
- 可以设定时刻**自动分析**，跑完提醒你（甚至把简报寄到你邮箱）。

**三点请先知道**：

1. **所有数据只存在这台电脑上**（`.env` 与 `data/` 目录），不会上传到任何服务器。
2. **发邮件和写日程都需要你逐封确认**，程序不会自己发出去。
3. 只有"分析邮件"这一步会把邮件正文送到你配置的**大模型服务商**（可换成本地模型，见下）。

---

## 一、装 Node.js

到 <https://nodejs.org> 下载 **LTS 版（20 或更高）**，一路默认安装即可。

装完可以用命令行验证：

```powershell
node -v      # 应输出 v20.x 或更高
```

## 二、下载并启动

1. 到 <https://github.com/Alexwuwei2022/mailbot> 点 **Code → Download ZIP**，解压到任意目录（例如 `D:\mailbot`）。
2. 双击 **`start.cmd`**（macOS/Linux 用 `./start.sh`）。
3. 首次启动会自动生成配置文件，并在命令行打印一个网址，例如 `http://127.0.0.1:8787`；
   浏览器通常会自动打开，没打开就手动访问那个地址。

> 命令行的窗口**不要关**——关了服务就停了。以后每次使用都是双击 `start.cmd`。

## 三、填三样东西（界面里照着填）

打开界面后，顶部「**设置**」页里依次完成：

### 1. 邮箱（必填）

| 填什么 | 从哪来 |
| --- | --- |
| IMAP 服务器 / 端口 | 你的企业邮箱帮助页。例如 `imap.example.com` / `993`（SSL 勾上） |
| SMTP 服务器 / 端口 | **注意：常常与 IMAP 不同**，例如 `smtp.example.com` / `465` |
| 账号 | 通常是完整邮箱地址 |
| 授权码 | **不是网页登录密码**！到邮箱设置里开启 IMAP/SMTP 后会给你一串"客户端专用密码/授权码" |
| 发件人姓名 | 会出现在你发出的邮件里 |

填完点「**测试连接**」，能列出文件夹就算通过。

### 2. 大模型（必填）

分析邮件要用大模型。到「设置 → 大模型」：

- 选一个服务商（内置 DeepSeek / OpenAI / 通义 / Kimi / 智谱 / **Ollama（本地）** 等预设）；
- 填 **API Key**（服务商官网申请），保存后点「测试」；
- **不想让邮件正文离开本机** → 选 **Ollama** 预设，在本机跑一个本地模型即可（界面里有指引）。

### 3. Google 日历（可选）

只有要用日历功能才需要。到「设置 → 日历」按提示创建 OAuth 凭据并点「连接 Google 日历」，
详细步骤见 [运行与配置文档 §10](运行与配置文档.md)。

> ⚠️ 授权有效期：如果 Google Cloud 里应用一直处于「**测试**」发布状态，授权**每 7 天**会失效一次，
> 需要重新点一次「连接」。想免掉这个周期就把发布状态改成「已发布」（个人自用不必通过验证）。

## 四、开始用

1. 回到「**邮件总览**」，点右上角「**分析最近 24 小时**」。第一次会告诉你大概要分析几封、花几次模型调用，确认后才开始。
2. 看「**需要你处理**」这一栏：点进任意一条可以看原文，右边按钮能起草回复、也能标记**已处理 / 稍后提醒 / 忽略**（清单因此可以被清空）。
3. 想让它自己动起来：「设置 → 定时分析与通知」设一个时刻（如 `08:30`）并打开开关。

## 五、常见问题

| 现象 | 怎么办 |
| --- | --- |
| 双击 `start.cmd` 一闪而过 | 说明没装 Node.js，回到第一步 |
| 端口被占用 / 想换端口 | 「设置 → 运行」里改端口，或在 `.env` 里设 `MAILBOT_PORT=`，改完重启 |
| 提示「授权码为空」 | 那是**邮箱授权码**没填（不是登录密码），见上面第 1 步 |
| 提示连不上 Google | 国内需要代理：在「设置 → 日历」填代理地址（**只支持 HTTP 代理**，不支持 SOCKS） |
| 分析报「大模型鉴权失败」 | API Key 不对或余额不足 |
| 界面时间与电脑不一致 | 「设置 → 日历时区」改成自己的时区即可（界面一律按它渲染） |
| 磁盘越来越大 | 「设置 → 存储与清理」可以看到占用并清理；邮件原文默认永久保留，可设保留期 |
| 换了电脑 / 重装 | 「设置 → 备份与恢复」导出压缩包，在新机器上导入 |
| 想彻底卸载 | 删掉整个程序目录即可；**注意 `data/` 里有你的邮件数据**，删前确认 |
| 不想让授权码以明文存在文件里 | 「设置 → 密钥存储」点「迁入」，密钥会搬进系统保管（Windows/macOS/Linux 各有对应机制）。注意：**换电脑后需要重新填一次**，因为密文与本机绑定 |

## 六、出问题时怎么反馈

到 <https://github.com/Alexwuwei2022/mailbot/issues> 提 issue，请附上：

1. 「设置 → 关于」里的**版本号**与 Node 版本；
2. 命令行窗口里的**报错原文**（可直接截图）；
3. 你做了什么操作（例如"点了分析最近 7 天之后报错"）。

**不要**贴出 `.env`、`data/config.json` 或截图里的授权码 / API Key。
